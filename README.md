# 假期倒计时

一个简洁的法定节假日倒计时页面，自动识别**下一个**即将到来的中国法定假期。

## 在线访问

启用 GitHub Pages 后访问：

**https://a912289748.github.io/holiday-countdown/**

## 本地预览

用浏览器直接打开 `index.html` 即可。

## 启用 GitHub Pages

1. 打开仓库 **Settings → Pages**
2. **Source** 选择 `Deploy from a branch`
3. **Branch** 选 `main`，文件夹选 `/ (root)`
4. 保存后等待 1–2 分钟

## 更新假期数据

编辑 `index.html` 中的 `HOLIDAYS` 数组。2026 年数据来自国办发明电〔2025〕7号；2027 年为预估，国务院正式通知发布后请更新。
